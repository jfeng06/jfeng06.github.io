04 / DIGITAL DESIGN

Single-Cycle RISC-V Processor

Building the core blocks of a processor, from the register file and ALU to decode and writeback.

In progressView source on GitHub ↗

The objective

Build a single-cycle RISC-V processor and develop a practical understanding of how instructions move through a datapath.

Current work

I have built the register file, arithmetic logic unit (ALU), decode, and writeback components. The repository contains the implementation developed so far.

Project status

The processor is not yet complete. Full-processor operation and instruction coverage are not claimed here. Project documentation is not available yet; the GitHub repository is the reference for the ongoing work.
